# 0010 — Deterministic at run time: no AI in any stage

Status: Accepted · 2026-08 · Source: `CLAUDE.md`; `docs/kuma-compile.md` "Why it exists"

## Context

The previous approach put the migration's intelligence in a Claude Code
skill that made mapping decisions *at run time*. That cannot be
reproducible, diffable, or testable, and it cannot be handed to a
colleague as "run this".

## Decision

The mapping file is the program. An AI may draft it; the plugin executes
it and makes no judgement calls of its own. Every decision the migration
takes is a line in a YAML file, reviewed in a PR. `CompileDeterminismTest`
and `BatchedCompileEquivalenceTest` hold the compile side to it.

## Consequences

- A skeleton generated by `init` deliberately does not guess a target:
  "a generator that filled in `block:` would be inventing the one decision
  a human is here to make, and the file would look finished while being
  wrong."
- `suggest` drafts rows for a human to accept; nothing accepts them
  automatically.
