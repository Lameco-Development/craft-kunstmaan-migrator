# Phase 8.1 — Proposer Correctness & Defensive Compile/Migrate

**Boundary:** Close the three correctness gaps surfaced by the Phase 8 rehearsal run against the CQM dump. Auto-mode inline execution (no /gsd-plan-phase invocation) — single small surface.

## What the rehearsal showed

A live `migrate --live --confirm --force` after running the new Phase 8 proposers against the CQM dump aborted at the taxonomies stage:

```
FAIL taxonomies: taxonomies[App\Entity\Employee]: missing targetSection/targetEntryType/sourceTable
```

Three taxonomy proposals had `status: accepted` but `targetSection: ''`:

- `App\Entity\Employee` → teamMember
- `App\Entity\NewsCategory` → newsCategory
- `App\Entity\PageParts\TextSectionPagePart` → textContentBlock

The third entry exposed the deeper bug: `proposeNonPageEntities` was classifying PagePart classes as taxonomy candidates. Per the operator's rule, **pageparts map to page-builder Matrix blocks. Both are global and not linked to a specific page.** PagePart classes are handled by step 7.6's `proposePagePartBlocks` — they should never appear in the non-page-entity index.

## Decisions

- **D-05a — Exclude PagePart classes from `proposeNonPageEntities` index.** The non-page-entity proposer is for genuine taxonomy/classifier shapes (CategoryX, TagY). PagePart classes belong to step 7.6. Filter applied in `AnalyzeController` step 7.7 setup: skip FQCNs that contain a `\PageParts\` namespace segment OR end with the `PagePart` suffix.

- **D-07a — Defensive `compileTaxonomies` skip.** `MappingCompiler::compileTaxonomies()` refuses to fold rows where any of `sourceTable` / `targetSection` / `targetEntryType` is empty, even when `status: accepted`. Emits a warning so the operator can re-run analyze or hand-fix mapping.yaml. The MappingAuditor still surfaces the audit finding (advisory) — D-07a is the defensive runtime guard at compile time.

- **D-08a — Soft-skip in `TaxonomyMigrationService::migrateAll`.** Hand-edited mapping.yaml entries can still slip past compile. migrateAll now increments `skipped` + emits a WARN on incomplete rows instead of throwing. The hard-fail at `migrateOneTaxonomy` line 139 is preserved as a defense-in-depth check that never fires in practice (D-07a + D-08a together short-circuit before reaching it).

## Out of scope (Phase 8.2)

The HomePage banner_* columns (heading/subheading/image/button_*) still don't flow into Craft after 8.1. These are direct columns on the page table that the existing proposers can't surface as Matrix layout blocks. The fix is to broaden the layout-block trigger heuristic (D-12 reshape) — that's a different design surface and gets Phase 8.2 if pursued.
