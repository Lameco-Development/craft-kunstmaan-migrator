    Add actions `actionQueueAnalyze()`, `actionQueueCompile()`, `actionQueueVerify()`, `actionQueueDryRun()`, and `actionQueueLive()` following `src/controllers/MappingController.php` for CP request validation, flash messages, and redirect style. Every action calls `requireCpRequest()`, `requirePostRequest()`, `requireAdmin()`, and `Plugin::getInstance()->migrationSafety->assertNotProductionForCp()` before creating run records or pushing queue jobs. `actionQueueLive()` also calls `requireElevatedSession()`. Every queue action blocks when `allowCpQueueActions === false`. `actionQueueLive()` additionally blocks when `allowCpLiveQueueAction === false`. Analyze requires body param `aiConfirmed=1` and API-key gate pass. Live requires phrase `MIGRATE LIVE`, backup acknowledgement, all gates passing, no unverifiable gate, and body param `warningsAccepted=1` passed into `MigrationGateService::liveGates(..., warningsAccepted: true)`. Queue actions create run records, push queue jobs, save queue job IDs via `markQueued()` / `appendQueueJobId()`, flash `Job queued. Progress will appear in the current run record.`, and redirect to Runs/detail without running workflows inline. Do not implement destructive `actionResetState()` or `actionCleanupArtifacts()` in Phase 12; they are explicitly deferred until a later plan defines exact deletion boundaries and tests.
