  <action>
    Add `actionBatch()` following `src/controllers/MappingController.php` CP POST validation, flash, and redirect style. It must require `requireCpRequest()`, `requirePostRequest()`, and `requireAdmin()`. Supported batch actions are exactly `accept`, `needs-review`, `drop`, and `accept-warnings`. For `drop`, require confirmation phrase `DROP SELECTED`. For `accept-warnings`, require phrase `ACCEPT WARNINGS`. Update selected row indexes using `MappingFile::updateRow()` only. Do not write raw YAML, create draft mapping files, or introduce database mapping storage.

  </acceptance_criteria>
  <done>
    Batch mapping actions are admin-only, phrase-protected where destructive/high-risk, and write only through canonical `MappingFile` helpers.
  </done>
