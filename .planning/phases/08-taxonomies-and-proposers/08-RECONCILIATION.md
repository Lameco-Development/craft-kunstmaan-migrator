## Open / deferred items

- **`relation:deferred` finalize-pass** (Phase 4.1 / REC-02): **stays unimplemented.** D-03 (taxonomies-before-pages run order, enforced by MigrateController::actionIndex Step 4.5 bolt-on) avoids the deferred-relation case entirely. Page entries' `RelationHandler` resolves category FKs via the existing `kunstmaanmigrator_state` table at FK→entryId lookup time. REC-02 remains documented in `04.1-CONTEXT.md` `## Deferred Ideas` for future scoping.
- **`--no-taxonomies` CLI flag**: **deliberately not added.** D-04 + Phase 2 / D-12 three-flag cap (`--entities`, `--locales`, `--since`) preserved. Operator's escape hatch is `taxonomies[fqcn].action: SKIP` (per-row, hand-edited post-compile) or omission of the row from `mapping.yaml`. Locked by Plan 08-12 wiring test (no `noTaxonomies` / `--no-taxonomies` strings in `MigrateController.php`).
- **D-09 fallback integration test** (Plan 08-15): currently `markTestIncomplete` — exercising the path requires either a Craft bootstrap or a deep `Craft::$app` shim. Plan 08-15 explicitly permitted the deferral; `testD09FallbackCopiesSourceLocaleAcrossSitesWhenExtTranslationsEmpty` carries a docblock with the deferral reason. The fallback IS implemented (lines 388-413) and gated by Doctor 11th check; the test seam is the only open thread.
- **Future taxonomy asset-field support**: Currently dropped (entry #14) since v2's compiler-emitted fields are flat `string => string`. Would require either a richer fields-shape (re-introducing `handler` keys per field) or a dedicated AttachService ride-along. Phase 8 deliberately does not preemptively design either.
