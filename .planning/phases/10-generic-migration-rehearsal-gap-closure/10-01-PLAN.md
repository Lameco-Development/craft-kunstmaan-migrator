# Plan 10-01: Compile/Preflight Safety and PageBuilder Ownership

## Goal

Prevent known load-fatal mapping states from reaching `migrate --live`, and prevent invalid PageBuilder Matrix ownership from causing runtime data loss.

## Task 1: Classify load-fatal Craft target validation

Files:

- `src/compile/CraftTargetIntrospector.php`
- `src/console/CompileController.php`
- `src/console/MigrateController.php`
- `tests/unit/compile/CraftTargetIntrospectorTest.php`
- `tests/unit/console/MigrateControllerFailureExitTest.php`

Action:

- Extend target validation so section + entry-type incompatibility is fatal, not advisory.
- Preserve warning-only behavior for advisory issues that cannot cause live `saveElement()` failure.
- Make `kunstmaan-migrator/compile` print fatal validation separately and return non-zero when load-fatal validation exists.
- Add a `migrate --live` preflight guard using `MigrateController::preflightCompiledMapping(...)` so stale invalid compiled artifacts cannot pass into live load.
- Do not add broad fallback to default entry type or default section.

Verify:

```bash
vendor/bin/phpunit tests/unit/compile/CraftTargetIntrospectorTest.php tests/unit/console/MigrateControllerFailureExitTest.php --testdox
```

Done:

- VacancyFormPage-style invalid `contentPages/formContentBlock` target is blocked before load.
- Advisory warnings still render without blocking.
- `migrate --live` refuses fatal compiled target states before extract/load.

## Task 2: Validate PageBuilder Matrix ownership before propagation

Files:

- `src/compile/MappingCompiler.php`
- `tests/unit/compile/MappingCompilerValidationTest.php`
- `tests/unit/compile/MappingCompilerPageRelationClosureTest.php`

Action:

- Propagate `pageBuilderHandle` only when the parent entry type owns the target Matrix field.
- If invalid ownership has an existing flat mapped target, keep the flat target and do not set `pageBuilderHandle`.
- If invalid ownership has no alternate mapped home, emit a blocking compile validation or explicit data-loss warning.
- Do not silently drop content.

Verify:

```bash
vendor/bin/phpunit tests/unit/compile/MappingCompilerValidationTest.php tests/unit/compile/MappingCompilerPageRelationClosureTest.php --testdox
```

Done:

- Parent-owned Matrix fields still propagate.
- Invalid Matrix ownership does not propagate.
- Invalid ownership is visible and source-preserving where a flat fallback exists.

## Acceptance Criteria

- Load-fatal mappings do not reach live load as runtime surprises.
- PageBuilder invalid ownership is blocked or visibly classified.
- No production code references CQM-specific classes, page IDs, or handles.
