# Plan 10-02: Load Fallback Hardening

## Goal

Make Craft validation-required fallback behavior generic and visible at the load boundary.

## Task 1: Add generic Matrix native-title fallback before Craft save

Files:

- `src/load/EntryMigrationService.php`
- `tests/integration/load/EntryMigrationServiceTest.php`

Action:

- Extend `EntryMigrationService::normalizeMatrixPayload(...)` or existing Matrix cleanup helpers.
- Prefer peer `title`, then lifted `fields.title`/`fields.heading`.
- If no usable title exists, synthesize a deterministic non-empty validation title from generic source metadata such as block type, position, or source ref.
- Preserve all existing block field values except established cleanup/lift behavior.
- Make fallback usage operator-visible.

Verify:

```bash
vendor/bin/phpunit tests/integration/load/EntryMigrationServiceTest.php --filter 'Matrix|Title|Fallback' --testdox
```

Done:

- ContactPage-style Matrix payloads no longer fail for missing native Matrix block title.
- Fields are preserved.
- Fallback messages are visible.

## Task 2: Add sparse-locale primary-save fallback

Files:

- `src/load/EntryMigrationService.php`
- `tests/integration/load/EntryMigrationServiceTest.php`

Action:

- Before primary-site `applyPerSiteData(...)`, detect missing or validation-empty primary payload for required native values such as `title`/`slug`.
- Select a best available non-empty source locale payload for the primary save only.
- Preserve original per-site payloads and source-driven enabled map.
- Do not create fake source locale data.
- Localized saves still apply their own payloads after primary save.
- Emit a visible fallback row/log.

Verify:

```bash
vendor/bin/phpunit tests/integration/load/EntryMigrationServiceTest.php --filter 'Sparse|Locale|Primary|Fallback' --testdox
```

Done:

- TextPage-style sparse locale payloads no longer fail primary-site blank title/slug validation.
- Locale enablement remains source-driven.
- Fallback messages are visible.

## Task 3: Ensure fallback reporting reaches operator artifacts

Files:

- `src/load/EntryMigrationService.php`
- `src/load/MigrationReport.php`
- `src/console/MigrateController.php`
- `tests/integration/load/EntryMigrationServiceTest.php`
- `tests/unit/console/MigrateControllerFailureExitTest.php`

Action:

- Prefer existing report/warning mechanisms rendered by `MigrateController::writeReport(...)`.
- If the load service cannot safely receive a report object, emit dedicated `Craft::warning(...)` messages and reference them from the report where a seam already exists.
- Include source entry, site/locale, and fallback category.

Verify:

```bash
vendor/bin/phpunit tests/integration/load/EntryMigrationServiceTest.php tests/unit/console/MigrateControllerFailureExitTest.php --testdox
```

Done:

- Matrix title fallback and sparse-locale fallback are visible as warnings/report rows.
- Successful fallback does not increment entry/stage failure counts.

## Acceptance Criteria

- ContactPage-style Matrix payload saves generically.
- TextPage-style sparse-locale payload saves generically.
- `storage/migration/REPORT.md` or run logs show all fallback usage.
- Production code remains generic.
