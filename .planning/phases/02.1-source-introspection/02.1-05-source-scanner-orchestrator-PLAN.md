    - Public method `public function scan(): array` that:
      1. Resolves source path (`$path = $this->pathResolver->resolve()`). If null, return an empty result shape (caller is gated already, but defensively).
      2. Pumps `$path` into `$this->entityParser->sourceCheckoutPath = $path` and calls `$this->entityParser->getAll()` to warm the FQCN-keyed entity map.
      3. Computes `tables`: union of (a) every `tableName` from each `DoctrineEntityInfo`, (b) every `joinTableName` from each ManyToMany `DoctrineRelationInfo`. Deduplicate. Sort.
      4. Computes `m2mJoins`: walk every entity's relations; for each ManyToMany with an explicit `joinTableName`, emit `['table' => $joinTableName, 'owning' => $entityFqcn, 'inverse' => $relation->targetEntity ?? null]`. Inverse-side relations (with `mappedBy`) cross-reference back to the owning side's joinTable.
      5. Calls `$this->bodyFinder->find()` (or whatever the v1 public accessor name is) to get bodyCols.
      6. Calls `$this->mediaScanner->find()` to get mediaFks.
      7. Computes drift: query `SELECT TABLE_NAME FROM information_schema.TABLES WHERE TABLE_SCHEMA = :db` (bound parameter — never concat) via `$this->legacyDb->queryAll(...)`. Compare with the discovered `tables` set:
         - `dbHasButScanMissing` = DB tables NOT in scan (filter out the `kuma_*` core via `KunstmaanCoreTables::all()`; only project content tables surface).
         - `scanHasButDbMissing` = scan tables NOT in DB.
      8. Return the structured array per the `<interfaces>` shape.
    - Use statements: `Craft`, `lameco\kunstmaanmigrator\db\LegacyDbService`, `yii\base\Component`.
    - Class docblock describing D-40 (left-side scanner over the v1 ports + drift detection).

    **Security:** All information_schema queries use bound parameters (T-02.1-02-03 pattern). Never string-concatenate operator-supplied DB name into the SQL literal.
