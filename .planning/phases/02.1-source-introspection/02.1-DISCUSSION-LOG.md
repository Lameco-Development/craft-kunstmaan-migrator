## Source path & fallback semantics

### Q1: How should the operator declare the Kunstmaan source path?

| Option | Description | Selected |
|--------|-------------|----------|
| Env var with Settings override | `KUNSTMAAN_SOURCE_PATH` env var primary; `Settings::kunstmaanSourcePath` overrides via `??=` (Phase 1 / D-12 pattern). | ✓ |
| Settings only, no env var | Path lives only in Settings::kunstmaanSourcePath. No env var support. | |
| CLI flag `--source-path=` | First-class CLI flag on analyze (and doctor), no Settings/env. | |

**User's choice:** Env var with Settings override.
**Notes:** Mirrors the established Phase 1 pattern for `legacyDb*`, `anthropicApiKey`. Operator-friendly: dev/staging hosts get `.env` entry; team-wide overrides go in config.

### Q2: Is `KUNSTMAAN_SOURCE_PATH` required for analyze, or does it have a graceful fallback?

| Option | Description | Selected |
|--------|-------------|----------|
| Optional — silent fallback to `kuma_*` LIKE (Recommended) | Roadmap's greenfield-mode intent. Plugin still runs without source path. Doctor's 5th check WARNs. | |
| Optional with WARN on every analyze run | Same fallback, but every analyze invocation prints a WARN line. | |
| Required for analyze | analyze hard-FAILs without `KUNSTMAAN_SOURCE_PATH`. Doctor's 5th check FAILs. | ✓ |

**User's choice:** Required for analyze.
**Notes:** Operator overruled the roadmap recommendation. Trade-off: plugin no longer installs into a Kunstmaan-source-less host gracefully. **Patches ROADMAP.md Phase 02.1 success criteria 1 + 3** (drop greenfield-fallback wording). Greenfield mode is dropped.

### Q3: When source-scan output and DB schema disagree, what's the default behavior?

| Option | Description | Selected |
|--------|-------------|----------|
| WARN by default, `--source-strict` opt-in (Recommended) | Mirrors Phase 2 / D-16 mapping-audit pattern. Findings persist; analyze continues. | ✓ |
| WARN only, no strict flag | Drift never blocks. CI can't gate. | |
| Hard-fail by default | Drift hard-FAILs analyze. Strictest. | |

**User's choice:** WARN by default, `--source-strict` opt-in.
**Notes:** Two drift categories: (i) DB has table not in scan, (ii) scan declares table missing from DB.

### Q4: Where in src/ does the Kunstmaan source path get read?

| Option | Description | Selected |
