    Implement the four private helpers + the public `scan()` orchestrator. AST-only — no code-execution primitives.

    **A. `extractMethodReturnArray(string $phpPath, string $methodName): array`** — uses nikic/php-parser:
    1. Read file with `file_get_contents`.
    2. Build parser: `(new ParserFactory())->createForHostVersion()` (or `createForVersion(...)` for PHP 8.3 — check what php-parser 5.x exposes; readme is the source of truth).
    3. Parse to AST: `$ast = $parser->parse($code)`.
    4. Walk the AST via `NodeTraverser` + `NodeVisitorAbstract` searching for a `Node\Stmt\ClassMethod` whose `->name->name === $methodName`.
    5. Within that method's `stmts`, find the first `Node\Stmt\Return_` whose `expr` is a `Node\Expr\Array_`.
    6. Walk the array items: each `Node\ArrayItem` has `value` (the array element). For `getPagePartAdminConfigurations` returning `['news_article', 'main']`, items are scalar strings. For `getPageTemplates` returning structured arrays, items may be nested arrays (recurse).
    7. Convert AST scalar nodes back to PHP values: `Node\Scalar\String_` → `$node->value`, `Node\Scalar\Int_` → `$node->value`, etc.
    8. Return the reconstructed PHP array. On any parse failure, `Craft::warning(...)` and return `[]`.

    **B. `extractDiscriminatorMap(string $phpPath): array`** — same AST-walk pattern, but searches for class-level `#[ORM\DiscriminatorMap([...])]` attribute (not method body):
    1. Find `Node\Stmt\Class_` (the entity class declaration).
    2. Walk `->attrGroups` → `->attrs[]` looking for an `Attribute` whose name resolves to `Doctrine\ORM\Mapping\DiscriminatorMap` (or just matches the suffix `\DiscriminatorMap` for use-aliased imports).
    3. Read its first arg, which is an array literal — convert via the same scalar-node handling.
    4. Return `['discriminatorValue' => 'FQCN', ...]` or `[]` if absent.

    **C. `scanPagePartsYaml(string $sourcePath): array`** — Symfony YAML reader:
    1. `$dir = $sourcePath . '/config/kunstmaancms/pageparts'`.
    2. If `!is_dir($dir)`, return `[]` (D-31 Discretion: WARN already emitted by doctor; here silently fall back).
    3. For each `*.yml` file in `$dir`, `Yaml::parseFile($file) ?? []`.
    4. Walk the parsed array looking for `kunstmaan_page_part.pageparts.{context}.types`. Each `types` entry has `{name, class}` keys.
    5. Return `['{context}' => [['name' => '...', 'class' => '...'], ...]]` keyed by context (filename basename without `.yml` is the context name when not present in the YAML).
    6. Catch any Yaml exception → `Craft::warning(...)` → skip that file.

    **D. `scanPageEntity(string $phpPath): array`** — composes A+B:
    1. Resolve the entity FQCN by reading the file's `namespace` declaration + the `class FooBar` line (use AST — find `Node\Stmt\Namespace_` + `Node\Stmt\Class_`).
    2. Resolve `tableName` via `$this->tableResolver->resolve($fqcn)` (catch InvalidArgumentException → use empty string).
    3. Call `extractMethodReturnArray($phpPath, 'getPagePartAdminConfigurations')` → contexts (raw context names).
    4. Call `extractMethodReturnArray($phpPath, 'getPageTemplates')` → templates.
    5. Call `extractDiscriminatorMap($phpPath)` → discriminatorMap.
    6. Return the structured per-FQCN array per `<interfaces>` shape.

    **E. `scan(): array`** — orchestrator:
    1. `$sourcePath = $this->pathResolver->resolve()`. If null, return `[]` (analyze/map already gate-failed in Plan 01; doctor's 5th check FAILed).
    2. Build YAML index once: `$yamlIndex = $this->scanPagePartsYaml($sourcePath)` (context → allowedClasses).
    3. Iterate `$sourcePath . '/src/Entity/Pages/*.php'` with a `RecursiveDirectoryIterator` rooted there. For each file:
       - Call `scanPageEntity($phpPath)`.
       - For each context this page declares, look up `$yamlIndex[$contextName]` to populate `allowedPagePartClasses`. For each `class`, call `$this->tableResolver->resolve($class)` to fill the `table` field.
       - When the YAML index is empty (config absence), `allowedPagePartClasses` stays empty for every context (PHP-only fallback per CONTEXT D-31 Discretion).
    4. Return `[$fqcn => $pageRecord, ...]` keyed by Page entity FQCN.

    **Security:** AST-only parsing — never `include`/`require` the source file, never use code-execution primitives. Every `tableResolver->resolve()` call MUST be wrapped in try/catch around `\InvalidArgumentException` (Plan 02 Task 3 contract) so unresolvable FQCNs degrade to `'table' => ''` rather than crashing the scan.
