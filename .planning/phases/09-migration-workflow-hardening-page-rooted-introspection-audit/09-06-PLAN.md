<objective>
Prevent CKEditor unresolved marker comments from becoming an injection/breakout vector.

User-facing outcome: editors can still find unresolved references, while malicious or malformed legacy URLs cannot terminate comments or inject renderable markup.
</objective>

<scope>
In scope:
- Encode raw legacy URL marker payloads using comment-safe base64url or equivalent per D-19.
- Keep the original unresolved URL in the `src`/`href` attribute.
- Add tests for `-->`, `<script`, quotes, and markup-looking URL values.

Non-goals:
- Do not remove unresolved markers.
- Do not drop the original attribute URL.
</scope>
