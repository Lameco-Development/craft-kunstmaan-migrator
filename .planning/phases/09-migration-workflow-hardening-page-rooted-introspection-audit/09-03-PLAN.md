<objective>
Harden the compile stage so bad mappings do not silently produce empty runtime output, and page-level relation gaps become compiled relation options or visible warnings.

User-facing outcome: operators see invalid mappings and unsupported relation shapes during compile instead of discovering missing content after rehearsal.
</objective>

<scope>
In scope:
- Compile validation for incompatible handler/source/target combinations per D-13.
- Page-level ManyToMany/OneToMany relation closure or visible unsupported-shape warnings per D-09 and D-21.
- Craft target introspection against compiled mapping per ROADMAP criterion 6: accepted target entry types, section/entry type compatibility, field handles, Matrix fields/block types, asset fields, Entries field sources, and SEOmatic/Retour adapter targets when plugins are enabled.
- Tests focused on compiler behavior.

Non-goals:
- Do not introduce a full generic embed/promote architecture unless required by the existing compile contract.
- Do not create Craft schema.
</scope>
