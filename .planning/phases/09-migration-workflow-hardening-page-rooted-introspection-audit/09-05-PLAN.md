<objective>
Make migration outcomes truthful and align asset preloading with the page-driven model.

User-facing outcome: partial success is reported as failure at process level, and asset preload cannot import the full legacy media table by default.
</objective>

<scope>
In scope:
- Add centralized `MigrationReport::hasFailures()` or equivalent.
- Change final `migrate` and `migrate/load` exit semantics per D-18.
- Change `--preload-assets` to referenced-only per D-20 using in-scope transformed/extracted payload references.
- Tests for both audit findings.

Non-goals:
- Do not stop on first entry failure.
- Do not add full orphan-media ingestion to `--preload-assets`.
</scope>
