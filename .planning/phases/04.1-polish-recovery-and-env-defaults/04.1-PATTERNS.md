## Risk callouts (load-bearing for the planner)

1. **`symfony/dotenv` is NOT installed.** CONTEXT.md D-04 claims it is "already a transitive dep — comes in via `symfony/console` chain". Verified false: `vendor/symfony/dotenv` does not exist, and `symfony/console` is also not in the dep tree (only `symfony/yaml` is required directly per `composer.json:18`). The planner MUST either (a) add `"symfony/dotenv": "^6.0 || ^7.0"` to `composer.json` `require`, or (b) drop the Dotenv dependency and roll a 30-line `.env` parser that handles the strict 2-key whitelist (no quoting / no interpolation needed; whitelist is `DATABASE_URL`, `DEFAULT_LOCALE`).

2. **No `config/` directory at repo root.** Plan 04.1-04 (D-17) ships `config/kunstmaan-migrator.example.php` — the planner MUST create the directory.

3. **`Settings` has NO `beforeValidate()` hook today.** Yii's `Model::beforeValidate()` is the right hook (D-07) but the override needs to be added; current `Settings::init()` is the only lifecycle hook in use (line 86-116). The planner can put the auto-fill logic either in `init()` (always runs) or `beforeValidate()` (only runs on save). D-07 specifies `beforeValidate()`; the planner should follow that explicitly.

4. **`MigrationFilters` is `final` with `readonly` properties** (`src/filter/MigrationFilters.php:17-29`) — three constructor args only (`entities`, `locales`, `since`). Adding `--no-seo` / `--no-retour` to it (D-26) requires changing the constructor signature, which ripples through `FilterFactory::fromCli` and every call site. A dedicated `AdapterFlags` VO is cleaner; CONTEXT explicitly leaves the choice to the planner.

5. **`MigrateController.php` is 1189 lines today** (verified end-of-file at line 1189). The 1107 / 1154 line numbers in CONTEXT.md D-41 are accurate snapshots of the current file (verified — `if ($skippedStageLines !== [])` is at line 1107, `if ($report->assetRcaRows !== [])` is at line 1154).

```php
/**
 * Phase 4.1 / D-07 — auto-fill blank legacyDb* from .env DATABASE_URL.
 * Operator-supplied Settings values always win; only blank slots fill.
 */
public function beforeValidate(): bool
{
    if ($this->legacyDbServer !== null && $this->legacyDbServer !== ''
        && $this->legacyDbDatabase !== null && $this->legacyDbDatabase !== ''
        && $this->legacyDbUser !== null && $this->legacyDbUser !== ''
    ) {
        return parent::beforeValidate(); // operator filled in everything; nothing to do
    }
    $reader = \lameco\kunstmaanmigrator\Plugin::getInstance()->kunstmaanEnvReader;
    $dsn = $reader->getDatabaseUrl();
    if ($dsn === null || $dsn === '') {
        return parent::beforeValidate();
    }
    $parts = parse_url($dsn);
    if (!is_array($parts) || !isset($parts['scheme'])) {
        return parent::beforeValidate();
    }
    // D-09: only mysql schemes are honored.
    $scheme = strtolower((string) $parts['scheme']);
    if ($scheme !== 'mysql' && $scheme !== 'mysql+pdo' && !str_starts_with($scheme, 'pdo:mysql')) {
        return parent::beforeValidate();
    }
    // D-08: percent-decode each component.
    $this->legacyDbServer   ??= isset($parts['host'])     ? urldecode((string) $parts['host'])     : null;
    $this->legacyDbUser     ??= isset($parts['user'])     ? urldecode((string) $parts['user'])     : null;
    $this->legacyDbPassword ??= isset($parts['pass'])     ? urldecode((string) $parts['pass'])     : null;
    if (isset($parts['path']) && $this->legacyDbDatabase === null) {
        $this->legacyDbDatabase = ltrim(urldecode((string) $parts['path']), '/');
    }
    if (isset($parts['port']) && $this->legacyDbPort === 3306) {
        $this->legacyDbPort = (int) $parts['port'];
    }
    return parent::beforeValidate();
}
```

Note: `??=` matches `Settings::init()`'s existing env-fallback ladder (lines 93-115) — the auto-fill is the same precedence shape, just with a different source.
