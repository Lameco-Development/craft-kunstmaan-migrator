## Implementation shape (Settings.php)

```php
public function beforeValidate(): bool
{
    // Fast path: every string field operator-filled → skip reader entirely.
    if ($this->legacyDbServer !== null && $this->legacyDbServer !== ''
        && $this->legacyDbDatabase !== null && $this->legacyDbDatabase !== ''
        && $this->legacyDbUser !== null && $this->legacyDbUser !== ''
        && $this->legacyDbPassword !== null && $this->legacyDbPassword !== ''
    ) {
        return parent::beforeValidate();
    }

    $reader = $this->getEnvReader();
    $dsn = $reader->getDatabaseUrl();
    if ($dsn === null || $dsn === '') {
        return parent::beforeValidate();
    }

    // D-09: non-mysql DSN → all parsed components null.
    if ($reader->getDsnHost() === null
        && $reader->getDsnUser() === null
        && $reader->getDsnDatabase() === null
    ) {
        return parent::beforeValidate();
    }

    $this->legacyDbServer   ??= $reader->getDsnHost();
    $this->legacyDbUser     ??= $reader->getDsnUser();
    $this->legacyDbPassword ??= $reader->getDsnPassword();
    $this->legacyDbDatabase ??= $reader->getDsnDatabase();

    $dsnPort = $reader->getDsnPort();
    if ($dsnPort !== null && $this->legacyDbPort === 3306) {
        $this->legacyDbPort = $dsnPort;
    }

    return parent::beforeValidate();
}
```

`parent::beforeValidate()` is invoked on every code path (4 return statements) — Yii's lifecycle hook semantics preserved.

## Deviations from Plan

### Auto-fixed issues

**1. [Rule 3 — Blocking] Empty behaviors() override required in test subclass**

- **Found during:** Task 1 (first test run after writing the file).
- **Issue:** Instantiating `Settings` outside a Craft / Yii bootstrap fails because `Settings::behaviors()` declares an `EnvAttributeParserBehavior` that Yii instantiates via `Yii::createObject()`. The unit suite has no Yii application bound, so `Class "Yii" not found` aborted every test before any logic ran.
- **Fix:** The test-only `Settings` subclass overrides `behaviors()` to return `[]`. This is safe because the env-attribute parser parses `$VAR`-string references at attribute-read time, and the tests inject the env reader directly via the `getEnvReader()` seam — no `$VAR` references appear in the values under test.
- **Files modified:** `tests/models/SettingsBeforeValidateTest.php` (private `makeSettingsWithEnv()` helper).
- **Commit:** Folded into `2c18bfb` (test commit).

**2. [Rule 1 — Plan-correction] Stub strategy switched from "mock" to "real reader via loadFromPath"**

- **Found during:** Task 1 (first test run).
- **Issue:** `KunstmaanEnvReader` is `final` (Plan 04.1-01 hardening). Anonymous-class extension fails at class-load time; PHPUnit's `createMock()` also can't subclass final without third-party tooling. The plan suggested either an anonymous-class subclass OR `createMock` — both blocked.
- **Fix:** Use a real `KunstmaanEnvReader` instance pre-loaded via its existing `loadFromPath()` test seam (the same escape hatch `KunstmaanEnvReaderTest` already uses). Each test writes a temp `.env.example`, points the reader at the temp dir, and feeds the loaded reader into the Settings subclass. Zero mocking, zero magic, behaviour matches production exactly.
- **Files modified:** `tests/models/SettingsBeforeValidateTest.php` (private `makeReader()` helper).
- **Net effect:** Plan acceptance criteria still hold — option A seam (`getEnvReader()` override) still in place.
- **Commit:** Folded into `2c18bfb`.

No code-level deviations from the plan in `src/models/Settings.php` — the implementation landed verbatim per the PATTERNS.md excerpt.
