<objective>
Build the foundation `KunstmaanEnvReader` Yii Component plus the doctor 9th check.
This plan owns the ONLY code path that reads a Kunstmaan project's `.env.example` /
`.env` files. It enforces a strict 2-key whitelist (`DATABASE_URL`, `DEFAULT_LOCALE`)
so secrets in `.env` (Mollie / SAML / ElasticSearch / GTM / reCAPTCHA / etc.) NEVER
enter the plugin's memory. Downstream plans (04.1-02 DB auto-fill, 04.1-03 locale
Rung 0) consume the reader at command-invocation time.

Purpose: Close the .env source-of-truth gap (operators currently configure DSN
twice — in Symfony `.env` AND in plugin Settings). Foundation for CFG-04, LOC-03.

Output: `KunstmaanEnvReader.php` + Plugin component registration + Doctor 9th
check + unit tests + `symfony/dotenv` composer require.

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04.1-01-01 | Information Disclosure | KunstmaanEnvReader | mitigate | Hard-coded 2-key WHITELIST const drops every other key before it lands in any field; secrets (Mollie/SAML/ElasticSearch) never enter memory. Test `testIgnoresKeysOutsideWhitelist` verifies. |
| T-04.1-01-02 | Tampering | parse_url DSN | mitigate | D-09 honors only mysql/mysql+pdo schemes — postgres://, file://, javascript: schemes return parsedDsn=null; downstream consumers see blanks (no SSRF / scheme confusion). |
| T-04.1-01-03 | Denial of Service | malformed .env | mitigate | Symfony Dotenv parse exceptions caught + logged via Craft::warning; reader marks loaded=true to prevent retry storm; `testMalformedEnvDoesNotThrow` verifies no escape. |
| T-04.1-01-04 | Information Disclosure | doctor 9th check | mitigate | Output lists FILE NAMES (.env / .env.example) and HOST (host-vs-settings comparison) but NEVER passwords or full DSN. Verify by greping the implementation: no `getDsnPassword` call inside the check. |

| T-04.1-01-06 | Repudiation | env file read silent failure | accept | D-06 mandates defensive (no throws). Operator-visibility lives in doctor 9th check output, not exceptions. Acceptable: env reader is best-effort by design. |
