<objective>
**TST-02 / D-01..D-05 — Transform-stage characterization tests against a real CQM corpus.**

The deliverable is the integration test that drives `TransformService` against ~10-15 captured legacy rows from CQM, comparing each output to a per-row golden file via canonicalized JSON diff. Once shipped, any change to TransformService that alters output (intentional or accidental) shows up as a fixture-diff in the same PR.

Three artifacts ship in this plan:

1. **`tools/capture-transform-fixtures.php`** — operator-side script (D-05; chose script over Dev console controller for simpler bootstrap). Run once on a dev host with KUNSTMAAN_SOURCE_PATH + CRAFT_LEGACY_DB_* configured against the CQM dump. Writes per-row JSON to `tests/fixtures/transform/input/<entity>/<id>.json`. NOT part of the test runner.

2. **`tests/integration/transform/TransformCharacterizationTest.php`** — the canonical TST-02 test. `@dataProvider fixtureProvider` discovers every input fixture, drives `TransformService`, JSON-canonicalizes the actual output (recursive ksort + JSON_PRETTY_PRINT), and diffs vs the golden. Missing golden -> failure with `UPDATE_SNAPSHOTS=1` instruction. `UPDATE_SNAPSHOTS=1` env var -> write/overwrite golden + markTestSkipped.

3. **Initial fixture corpus** — captured once via the script, committed verbatim. Target: 4-5 entity types (PageNode, NewsPage, ContactPage, plus 1-2 entities with MatrixHandler blocks; planner/operator picks from CQM extract). ~10-15 input rows total. Goldens generated by first test run with `UPDATE_SNAPSHOTS=1`.

Why this is Wave 2 (not Wave 3): no dependency on 05-02's coverage tooling. The characterization test produces TST-02 signal (golden-file stability), not TST-01 coverage. Parallel with 05-02 + 05-04 (no file overlap).

PATTERNS risk callout 7: JSON canonicalization is required. PHP's `json_encode` does NOT sort keys by default. The comparator does recursive ksort on associative arrays (preserving list ordering via `array_is_list`) before encoding. Without this, every PHP version bump or array-key insertion-order change becomes a fixture diff.

- Capture script written, lint-clean (operator runs it on a dev host with CQM access — that capture is operator-side and may extend beyond this plan's CI window)
- Test file shipped with @dataProvider + canonicalize-then-diff comparator
- Fixture corpus committed: 10-15 input rows + matching goldens (operator runs UPDATE_SNAPSHOTS=1 to seed goldens once inputs are in place)
- `composer test-integration` discovers and runs the new test
- The test is the first inhabitant of `tests/integration/transform/` (subdir created in this plan)

    final class TransformCharacterizationTest extends TestCase
    {
        /**
         * @return iterable<string, array{string, string}> rel => [inputPath, goldenPath]
         */
        public static function fixtureProvider(): iterable
        {
            $base = __DIR__ . '/../../fixtures/transform';
            $inputBase = $base . '/input';
            if (!is_dir($inputBase)) {
                return;
            }
            $matches = glob($inputBase . '/*/*.json') ?: [];
            sort($matches);
            foreach ($matches as $inputPath) {
                $rel = substr($inputPath, strlen($inputBase . '/'));
                $goldenPath = $base . '/golden/' . $rel;
                yield $rel => [$inputPath, $goldenPath];
            }
        }

        /**
         * @dataProvider fixtureProvider
         */
        public function testTransformRowMatchesGolden(string $inputPath, string $goldenPath): void
        {
            $rawJson = file_get_contents($inputPath);
            self::assertNotFalse($rawJson, "Input fixture unreadable: {$inputPath}");
            $input = json_decode($rawJson, true);
            self::assertIsArray($input, "Input fixture not a JSON object: {$inputPath}");

            $service = self::createService();
            // Public transform method — verify the actual surface in src/transform/TransformService.php
            // and adjust the call below if the real method is named transformEntry / transform / etc.
            $actual = $service->transformRow($input);

            $actualJson = self::canonicalize($actual);

            $update = getenv('UPDATE_SNAPSHOTS') === '1';
            if (!is_file($goldenPath)) {
                if ($update) {
                    @mkdir(dirname($goldenPath), 0755, true);
                    file_put_contents($goldenPath, $actualJson);
                    self::markTestSkipped("Golden refreshed: {$goldenPath}");
                    return;
                }
                self::fail("Golden missing: {$goldenPath} (set UPDATE_SNAPSHOTS=1 to create)");
            }

            $expected = (string) file_get_contents($goldenPath);
            if ($update && $expected !== $actualJson) {
                file_put_contents($goldenPath, $actualJson);
                self::markTestSkipped("Golden updated: {$goldenPath}");
                return;
            }

            self::assertSame($expected, $actualJson, "Diff vs golden: {$goldenPath}");
        }

        /**
         * Build a TransformService with the smallest possible stub dependencies.
         * Adjust as the constructor signature evolves; per D-01 we instantiate
         * directly and feed rows in — no DB, no Craft container.
         */
        private static function createService(): TransformService
        {
            // EXECUTOR: inspect src/transform/TransformService.php constructor.
            // Build with stubs for each dep. Common shape: TransformService(
            //   FieldHandlerRegistry $handlers,
            //   MappingFile $mapping,
            //   LegacyDbService $legacyDb,    // may not be required for transformRow path
            //   ...

            // construct (e.g. MappingFile::fromArray([...]) if the helper exists).
            // If the public transform method takes a $mappingRow param explicitly, the

            return new TransformService(/* stubs/real-deps per inspection */);

        /**
         * D-Risks #7 / PATTERNS callout 7 — recursive ksort that preserves list
         * ordering, then encode with stable flags + trailing newline.
         */
        private static function canonicalize(mixed $value): string
        {
            $sort = static function (mixed &$v) use (&$sort): void {
                if (is_array($v)) {
                    if (array_is_list($v)) {
                        // List: preserve ordering; recurse into items.
                        foreach ($v as &$item) {
                            $sort($item);
                        }
                        unset($item);
                    } else {
                        // Associative: ksort + recurse.
                        ksort($v);
                        foreach ($v as &$item) {
                            $sort($item);
                        }
                        unset($item);
                    }
                }
            };
            $sort($value);
            $json = json_encode(
                $value,
                JSON_PRETTY_PRINT | JSON_UNESCAPED_SLASHES | JSON_UNESCAPED_UNICODE,
            );
            if ($json === false) {
                throw new \RuntimeException('json_encode failed: ' . json_last_error_msg());
            }
            return $json . "\n";
        }
