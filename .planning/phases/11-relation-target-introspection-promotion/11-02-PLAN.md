# Plan 11-02: KunstmaanPageWalker

<objective>
Build `KunstmaanPageWalker`, a scoped, recursive, cycle-safe source graph walker that starts from Kunstmaan Page roots and emits a normalized versioned graph.
</objective>

  <action>
    Create `KunstmaanPageWalker` as a Yii `Component` in namespace `lameco\kunstmaanmigrator\source`. Add nullable public dependencies `?KunstmaanSourcePathResolver $pathResolver`, `?DoctrineEntityParser $entityParser`, `?KunstmaanSourceScanner $sourceScanner`, and `?KunstmaanPageStructureScanner $pageStructureScanner`. Implement `public int $maxDepth = 4` and `public function walk(array $rootShortNames = [], ?int $maxDepth = null): array`. Output a normalized array with `graphVersion`, `roots`, `entities`, `relations`, `assets`, `tables`, `samples`, and `constraints`. Resolve roots by short class names such as `NewsPage` and `HomePage` from parsed FQCNs under `App\Entity\Pages\*`. Follow Doctrine relation targets recursively with a visited set keyed by FQCN and depth. Represent shared relation targets once under `entities`; add inbound owner evidence rows containing owner FQCN, owner property, source column/FK if available, target FQCN, and relation type. Include relation intent candidates using exact categories `reference`, `promote`, `embed`, `drop`, `out_of_scope`; do not decide final intent in the walker. Include content-like columns factually as entity columns only; do not create implicit generic pagepart mappings. Return a parseable versioned empty graph when source path/parser is unavailable.
  </action>

<threat_model>
| Threat | Severity | Mitigation |
|---|---|---|
| Recursive source walking can loop or over-expand. | High | Use a visited set and configurable `maxDepth`. |
| Source introspection executes untrusted Kunstmaan PHP. | High | Reuse parser/scanner read-only patterns; never include/eval source files. |
| Fake pageparts or copied relation blobs become canonical data again. | High | Acceptance criteria reject `__implicit_content__`; owner data stays factual. |
</threat_model>
